# The Keyboard Shortcuts editor

Open the Keyboard Shortcuts editor with {{Ctrl+K Ctrl+S}}. Press {{Ctrl+K}}, let go, then press {{Ctrl+S}}. This is a chord, which the chord lesson covers later.

The editor lists every command in VS Code, with its shortcut beside it, if it has one. A search box at the top finds commands by name, by shortcut, or by the words in their description.

## An example

Suppose you often open the terminal, and want to know its shortcut. Type `toggle terminal` into the search box. The list narrows to the commands with those words. Find `Terminal: Toggle Terminal`. Its shortcut appears in the Keybinding column, as {{Ctrl+`}}.

You can also search by the shortcut itself. Type `ctrl+`` in the search box, and every command bound to that key appears. This is how you check what a key does before you use it for something else.

## Why this matters

Many commands have no shortcut at all. If you use one often, the editor lets you give it one. The next lesson shows how.

> **Search by name first.** If you do not know a command's name, describe what it does, such as `duplicate` or `comment`, and read the results.
