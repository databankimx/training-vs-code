# The Settings editor

Open the Settings editor with {{Ctrl+,}}. It opens in a tab, with a search box at the top and a list of settings grouped by topic, such as Editor, Files, and Terminal.

![Figure 22.1 - The Settings editor](images/ch22-settings-editor.png)

*Figure 22.1 - The Settings editor, with the search box at the top*

## An example

Suppose the text in the editor is too small. Type `font size` in the search box. The list narrows to settings with those words in their name or description. Find `Editor: Font Size`, which is 14 by default. Change it to 16. The change takes effect straight away, and the text in every open file grows.

## What each setting looks like

Each setting has a name, a description, and a value. Some values are checkboxes, some are numbers, and some are dropdown menus. Settings you have changed are marked, so you can see what you have touched.

## Putting it back

Each changed setting has a gear icon. Click it, and choose Reset Setting to return the value to its default. Try this with the font size, so you know the way back.

> **The Settings editor is the friendly view.** Behind it is a JSON file, which the next lesson opens. Both show the same settings.
