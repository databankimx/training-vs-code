# Checklist: typing and moving text

Work through this list in the practice folder. Use calculator.py for the first items, and undo any change you do not want to keep.

- [ ] {{Ctrl+Z}} undoes a change, and {{Ctrl+Y}} redoes it.
- [ ] {{Alt+Up}} and {{Alt+Down}} move a line in calculator.py, and you moved it back.
- [ ] {{Shift+Alt+Down}} copies a line, and you deleted the copy with {{Ctrl+Shift+K}}.
- [ ] {{Ctrl+/}} comments out a line, and pressing it again removes the comment.
- [ ] {{Alt+Z}} turns word wrap on and off.
- [ ] You expanded `ul>li*3` into a list in an untitled HTML file.
- [ ] calculator.py now matches the solution in the homework step.

Chapter 5 uses several cursors at once, in the same practice folder.
