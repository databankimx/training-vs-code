# Checklist: finding and navigating

Tick each item when you have done it in VS Code. Use the practice folder for every item.

- [ ] Find `total` in `calculator.py` with {{Ctrl+F}}, and step through its matches with {{Enter}}.
- [ ] Turn on Match Whole Word with {{Alt+W}}, and explain in one sentence why it matters when you replace a name.
- [ ] Search the whole practice folder with {{Ctrl+Shift+F}}, and open one result from the list.
- [ ] Narrow a search to Python files with the Files to include box, using `*.py`.
- [ ] Use {{Ctrl+G}} to go to a line number you choose, and {{Ctrl+Shift+O}} to list the symbols in `calculator.py`.
- [ ] Use {{Alt+Left}} to go back after you jump somewhere, and {{Alt+Right}} to go forward again.
