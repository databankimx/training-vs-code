# Profiles

A profile is a named set of settings, extensions, keyboard shortcuts, and snippets that you can switch between. Profiles help when one set of tools suits one kind of work, and a different set suits another.

## An example

You might keep a Writing profile with a larger font, word wrap on, and only the extensions you need for Markdown. You might also keep a Coding profile with the rulers, the terminal settings, and the language extensions. Switching profiles changes the editor's look and tools in one step, without you editing the settings file by hand.

## Creating and switching

Look for the profile menu at the lower left of the window. From there, choose Create Profile, give the profile a name, and choose what to copy into it. To switch, choose the profile from the same menu. The window and its tools change to match.

## Copy with care

When you create a profile, you choose what to copy from the current one. Copying everything brings along its extensions and settings. Start from a blank profile when you want a clean set, and add only what that kind of work needs.

> **Each profile keeps its own settings.** Changing a setting in one profile does not change it in another.
