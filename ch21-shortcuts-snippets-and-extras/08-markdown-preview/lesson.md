# Markdown preview

Markdown is a plain-text format for documents, and the `.md` files in the course are written in it. VS Code shows a rendered preview of a Markdown file, so you can see how it will look before you share it.

## An example

Open `README.md` in your practice folder. Press {{Ctrl+Shift+V}} to open the preview in place of the editor. The headings, lists, and links appear as they will to a reader. Press {{Ctrl+Shift+V}} again to go back to the source.

For side-by-side work, press {{Ctrl+K}}, let go, then press {{V}}. The preview opens beside the source, and it updates as you type. This is the view to use when you are writing a long document.

## Why it helps

A list with the wrong indent, or a link with a missing bracket, can look fine in the source and broken in the preview. Checking the preview catches that before a reader does.

> **The preview is a view, not a copy.** It shows the file as it is. Changing the preview changes nothing, so edit the source.
