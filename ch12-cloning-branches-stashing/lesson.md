# 11. Cloning, Branches, Stashing, and Undo

Chapter 3 cloned the practice repository in PowerShell. This chapter does the same job from inside VS Code, and then uses that second copy to work with branches, stashes, and undo.

A branch is a separate line of commits. You use one when you want to try something without touching `main`. A stash is a shelf for changes you are not ready to commit. Undoing the last commit is for the commit you just made and did not mean to make.

The work in this chapter happens in VS Code's own state, so each step is a checklist item. Where Git can confirm the result, the lesson gives the terminal command to run and check.

Use a second folder for this chapter, such as `C:\Development\training\branches-practice`. Leave `training-vs-code-practice` alone, because it still holds the commit and the changes from Chapter 11.
