# 18. Checking What Copilot Writes

Copilot is fast, and it is often right. It is also wrong in ways that look right, which is harder to spot than an obvious error. This chapter is about the habit that catches those errors. You own the code you commit, and you check every suggestion before you keep it.

> **Copilot use rule.** The free tier of GitHub Copilot is permitted for learning, and this course uses it for that purpose. Use it only with the sample code in this course, and never for DataBank work. DataBank work happens only through company-provided accounts, under the AI Acceptable Use Policy.
