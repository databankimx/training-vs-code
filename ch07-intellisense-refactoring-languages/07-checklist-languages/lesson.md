# Checklist: IntelliSense and languages

Tick each item when you have done it in VS Code.

- [ ] Open the completion list with {{Ctrl+Space}} in `totals.js`, and insert a name from it.
- [ ] Show the parameter hints for `add(` with {{Ctrl+Shift+Space}}, and read the names it shows.
- [ ] Read a hover description with {{Ctrl+K}}, then {{Ctrl+I}}, on a name in `calculator.py`.
- [ ] Install the Python extension, published by Microsoft, from the Extensions view.
- [ ] Create a `.venv` in the practice folder with `py -m venv .venv`, and activate it with `.\.venv\Scripts\activate`.
- [ ] Check that `where.exe python` shows a path inside `.venv`.
- [ ] Select the `.venv` interpreter with {{Ctrl+Shift+P}}, then Python: Select Interpreter, and check the status bar.
- [ ] Rename a symbol with {{F2}}, read its preview, and cancel it with {{Esc}} unless you want the change.
- [ ] Open Quick Fix with {{Ctrl+.}} on an underlined name, and read its options before you choose one.
- [ ] Open the Problems panel with {{Ctrl+Shift+M}}, and jump from one entry to its line.
