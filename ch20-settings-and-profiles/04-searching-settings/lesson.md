# Searching settings

You do not need to know a setting's name to find it. Open the Settings editor with {{Ctrl+,}}, and search for words that describe what you want.

## Examples

- Search `word wrap` to find the setting that wraps long lines in the editor.
- Search `format on save` to find the setting that formats a file each time you save it.
- Search `@modified` to list only the settings you have changed from their defaults.

Each result shows the setting's name, so you learn the name as you search.

## Reading the name

Once you know the setting you want, read its name in the Settings editor, or type it into `settings.json` by hand. Checking the name against the Settings editor before you save is the cheap way to avoid typos.

> **Search by purpose.** When you do not know the name, describe what you want to change, and then read the names that come back.
