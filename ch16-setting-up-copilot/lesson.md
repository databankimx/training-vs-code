# 16. Setting Up GitHub Copilot

GitHub Copilot is an AI assistant that works inside VS Code. It suggests code as you type, and it answers questions about the code you have open in a chat panel. This chapter sets it up, and the next two chapters use it.

> **Copilot use rule.** The free tier of GitHub Copilot is permitted for learning, and this course uses it for that purpose. Use it only with the sample code in this course, and never for DataBank work. DataBank work happens only through company-provided accounts, under the AI Acceptable Use Policy.

If you want a more in-depth exploration of AI-assisted coding, the [AI-Assisted Coding tutorial](https://github.com/databankimx/training-ai-assisted-coding) goes further than this part of the course. It is optional, and you can work through it at any time, before or after this chapter.

Copilot can be wrong. Chapter 18 is about checking what it writes, and that check matters more than anything else in this part of the course.
