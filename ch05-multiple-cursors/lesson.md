# 5. Multiple Cursors and Column Selection

Sometimes the same change has to happen in several places at once: the same word on every line, the same character at the start of each row, or the same value in a list. You could make each change one at a time. VS Code can make them all in one go, by giving you more than one cursor. Anything you type or delete applies at every cursor.

This chapter covers adding cursors, selecting every match of a word, and selecting a column of text. Early in the chapter you create a Python file, `prices.py`, in your practice folder. The homework then changes the list of values in it.
