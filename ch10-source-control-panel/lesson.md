# 10. The Source Control Panel

Every change you make to the practice repository is tracked by Git. VS Code shows those changes in the Source Control view, so you can see what changed, look at each change line by line, choose what goes into a commit, and write the commit message, all without leaving the editor.

This chapter uses the Git that Chapter 3 installed, and the practice repository you cloned there. It does not push anything to GitHub. Pushing is the subject of Chapter 12.

Your practice folder may already have changes from earlier chapters, such as an untracked `report.py`. Those changes are real, and the Source Control view will show them. In this chapter you commit only `README.md`, and you leave the others alone.

Every step here is a checklist step. The chapter has no homework, because the work is in VS Code's own state: what is staged, what is committed, and which branch you are on.
