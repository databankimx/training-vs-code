# Chapter summary

You can now accept, dismiss, and cycle suggestions, ask questions in the chat panel, add context, and pick the right mode.

- Ghost text is a proposal. Tab accepts it, and Esc dismisses it.
- The chat panel opens with {{Ctrl+Alt+I}}.
- #file and @workspace add context to a question.
- Start in Ask mode, and move to Edit or Agent only when you can review every change.

```quiz
What does Esc do with a ghost text suggestion?
○ It accepts the suggestion.
→ Tab accepts. Esc does not.
◉ It dismisses the suggestion, and the file stays as it was.
→ Esc removes the suggestion without changing the file.
○ It sends the suggestion to the service.
→ Esc does not send anything. It dismisses the suggestion.
○ It undoes your last change.
→ Esc dismisses a suggestion. Use Ctrl+Z to undo a change.
```

```quiz
Which mode should you start with for questions in this course?
○ Agent, because it does the most work.
→ Agent changes files in several steps, so start with Ask.
○ Edit, because it changes files for you without review.
→ Edit proposes changes for you to review. It does not apply them without you.
○ Any mode is fine.
→ The modes differ in how much they change, so the choice matters.
◉ Ask, because it answers questions and does not change files.
→ Ask is the safest starting mode for questions.
```

```quiz
What does #file do in a chat question?
◉ It adds a file you name to the question as context.
→ That is the job of #file.
○ It saves the chat to a file.
→ #file adds a file to the question. It does not save anything.
○ It creates a new file.
→ #file adds an existing file to the question.
○ It deletes the file from the project.
→ #file does not change files.
```
