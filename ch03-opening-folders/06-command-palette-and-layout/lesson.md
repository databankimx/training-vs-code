# The command palette and the window layout

Chapter 0 introduced the command palette. Press Ctrl+Shift+P, type a few letters of what you want, and press Enter. Almost every action in this chapter can be reached that way, so when you forget a shortcut, use the palette.

![Figure 3.5 - The command palette with a search typed in](images/ch03-command-palette.png)

*Figure 3.5 - The command palette with a search typed in*

## Showing and hiding parts of the window

Each part of the window can be hidden when you do not need it. This keeps the code in view, and it brings the part back when you do.

- Ctrl+B shows or hides the side bar on the left.
- Ctrl+J shows or hides the panel at the bottom, where the terminal and the Problems list live.

## Splitting the editor

Split the editor when you want to compare two files, or read one while you edit another. Press Ctrl+\ to split the editor, and each side can show a different file. Open a file in the other side by choosing it from Quick Open or the Explorer.

![Figure 3.6 - The editor split into two side-by-side panes](images/ch03-split-editor.png)

*Figure 3.6 - The editor split into two side-by-side panes*

## Moving the panel

The panel sits along the bottom of the window by default. Some people prefer it on the right, where it leaves more room for a tall file. To move it, drag the panel's tab bar toward the side of the window. VS Code shows where it will land while you drag.

![Figure 3.7 - The panel moved to the side of the window](images/ch03-panel-moved-side.png)

*Figure 3.7 - The panel moved to the side of the window*

## Zen Mode

Zen Mode hides everything except the editor, so you can focus on one file. Press Ctrl+K, then Z, one after the other. Press Esc twice to leave it.

![Figure 3.8 - The window in Zen Mode, showing only the editor](images/ch03-zen-mode.png)

*Figure 3.8 - The window in Zen Mode, showing only the editor*

## Zoom

If the text is too small or too large, press Ctrl+= to zoom in, Ctrl+- to zoom out, and Ctrl+0 to return to the default size. The zoom applies to the whole window.
