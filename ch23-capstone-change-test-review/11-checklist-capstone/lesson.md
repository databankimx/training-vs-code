# Checklist: the capstone

Tick each item when you have done it.

- [ ] Open the practice repository, and check that the branch is `main` and the Changes list is empty.
- [ ] Create the branch `fix-price-test`, and check the branch name in the status bar.
- [ ] Use multiple cursors to find both occurrences of `seven` in `test_calculator.py`.
- [ ] Run `python -m unittest` in the terminal, and read the one failure.
- [ ] Debug the failing test from the Testing view, and read the value that `total` returns.
- [ ] Make the change in the test, and run the tests until they pass.
- [ ] Review the diff, and check that `calculator.py` is unchanged.
- [ ] Stage the change, and commit it with a clear message.
- [ ] Publish the branch with `Git: Publish Branch...`.
- [ ] Open a pull request, with a description a reviewer can follow.
- [ ] Ask Copilot to explain `total`, and check its explanation against the test.
