# 6. Finding, Replacing, and Navigating

A file is easy to read when it is short. Most real code is not short, and the question is usually where something is: where a name is used, where a value is set, or which file holds a function you need to change. This chapter covers the tools VS Code gives you for finding text, replacing it safely, and moving between the places that matter.

Most of the practice happens in `calculator.py` in your practice folder. The last step is homework, which renames a function using Find and Replace. Each part ends in a checklist, and the chapter closes with a short summary and quiz.
