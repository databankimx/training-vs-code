# Checklist: setting up Copilot

Tick each item when you have done it in VS Code.

- [ ] Confirm you are signed in with your personal account, not a company account.
- [ ] Click the robot icon in the status bar, and select Sign in.
- [ ] Open the robot icon's menu, and check that the plan shows Copilot Free.
- [ ] Check that Inline Suggestions shows Enabled.
- [ ] Turn suggestions off, then on again.
- [ ] Find the Copilot settings in the Settings editor.
