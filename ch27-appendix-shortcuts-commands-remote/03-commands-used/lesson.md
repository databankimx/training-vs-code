# Commands used in the course

Press {{Ctrl+Shift+P}}, and type a command's name to run it. Names here match the Command Palette, so you can search for them exactly as written.

## Preferences and settings

- `Preferences: Open User Settings (JSON)`: opens `settings.json`. Chapter 22.
- `Preferences: Open Keyboard Shortcuts (JSON)`: opens `keybindings.json`. Chapter 23.
- `Snippets: Configure User Snippets`: opens the snippets file for a language. Chapter 23.
- `Format Document`: formats the open file. Chapter 4.
- `Toggle Line Comment`: comments or uncomments the line. Chapter 4.

## Python

- `Python: Select Interpreter`: chooses the Python version VS Code uses. Chapter 7.
- `Python: Configure Tests`: sets up the Testing view for the tests. Chapter 11.

## Terminal and tasks

- `Terminal: Toggle Terminal`: shows or hides the terminal. Chapter 8.
- `Terminal: Clear`: clears the terminal. Chapter 8.
- `Terminal: Select Default Profile`: chooses the shell the terminal opens. Chapter 8.
- `Tasks: Run Task`: runs a task from `tasks.json`. Chapter 8.
- `Tasks: Run Test Task`: runs the test task. Chapter 8.

## Git

- `Git: Clone`: clones a repository from GitHub. Chapter 13.
- `Git: Create Branch...`: creates a branch. Chapters 14 and 25.
- `Git: Delete Branch...`: deletes a branch. Chapter 13.
- `Git: Stash`, `Git: Stash (Include Untracked)`, `Git: Apply Latest Stash`, `Git: Pop Latest Stash`: set changes aside and bring them back. Chapter 13.
- `Git: Fetch`, `Git: Pull`, `Git: Push`: move commits to and from the remote. Chapter 14.
- `Git: Publish Branch...`: copies a new branch to GitHub. Chapters 18 and 25.
- `Git: Merge...`: merges a branch into the current one. Chapter 15.
- `Git: Undo Last Commit`: undoes the last commit, and keeps the changes. Chapter 12.
- `Sync Changes`: the button that pulls and pushes together. Chapter 14.

## Debugging, output, and trust

- `Developer: Show Logs...`: opens VS Code's logs. Chapter 24.
- `Developer: Reload Window`: restarts the window without losing work. Chapter 24.
- `Workspaces: Manage Workspace Trust`: changes whether a folder is trusted. Chapter 24.
