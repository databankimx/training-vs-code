# Creating a GitHub account

If you already have a GitHub account for practice, skip to the next step, but check that its email address is one you can read, and that two-factor authentication is on.

## Sign up

Go to github.com and choose Sign up. GitHub asks for an email address, a password, and a username, in that order. Pick the username carefully. It appears in web addresses and in the names of your repositories, and it is hard to change without breaking links.

![Figure 2.1 - GitHub sign-up page](images/ch02-github-sign-up.png "width=50%")

*Figure 2.1 - GitHub sign-up page*

Choose a username that is yours and is easy to read, such as your first name with your last initial. Leave out anything that names your employer.

## Verify your email address

GitHub sends a message to the address you gave, with a code or a link to confirm it. Until you confirm, some features stay locked, and the course needs them.

![Figure 2.2 - Verification email message](images/ch02-verification-email.png)

*Figure 2.2 - Verification email message*

If the message does not arrive within a few minutes, check your spam folder. Then choose the option to resend it from the GitHub page that asks for it.

## Turn on two-factor authentication

Two-factor authentication asks for a second proof of who you are when you sign in, usually a code from an authenticator app. It is strongly recommended, and some of the sign-in steps in later chapters are easier with it on.

Open your account settings, choose Password and authentication, and follow the steps for two-factor authentication. Use an authenticator app on your phone. When GitHub shows you recovery codes, save them somewhere safe, such as a password manager. They are the only way back in if you lose the phone.

![Figure 2.3 - Two-factor setup page](images/ch02-two-factor-setup.png)

*Figure 2.3 - Two-factor setup page*

> **Lost your phone?** Use one of the recovery codes you saved. Without them, GitHub support has to verify you by other means, which takes time. Save the codes before you leave the setup page.
