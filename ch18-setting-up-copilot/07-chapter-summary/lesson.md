# Chapter summary

Copilot is set up. It suggests code and answers questions, but it can be wrong, and you check what it writes.

- Signing in from the robot icon in the status bar is the only setup step.
- Use your personal account, on the free tier, only with the sample code in this course.
- DataBank work uses only the company-provided account, under the AI Acceptable Use Policy.
- Do not send confidential data to Copilot.

```quiz
What does the chat part of Copilot do?
○ It suggests code as you type.
→ That is the suggestions part. Chat is the panel where you ask questions.
○ It runs your code and checks that it is correct.
→ Copilot does not run or check code. Chapter 20 explains why.
◉ It adds a panel where you ask questions about the code.
→ Chat answers questions about the code you have open.
○ It stores your passwords.
→ Copilot does not store passwords, and you should never send them to it.
```

```quiz
Which account do you use for DataBank work?
◉ The company-provided account, under the AI Acceptable Use Policy.
→ DataBank work goes through the company-approved account only.
○ Your personal account on the free tier.
→ The free tier is for learning, with the sample code only.
○ Any account you already have signed in.
→ Only the company-provided account is used for DataBank work.
```

```quiz
Before you send a file to Copilot, what should you check?
○ Nothing. Copilot never sends code anywhere.
→ Copilot sends the code around your cursor and any files you include, to the service.
○ That the file is written in Python.
→ The language does not decide whether the file can be shared.
○ That the file has a docstring.
→ Docstrings have nothing to do with what Copilot may see.
◉ That the file has no confidential data, such as passwords, keys, or customer records.
→ Keep confidential data out of Copilot, on every account.
```
