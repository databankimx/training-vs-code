# Chapter summary

You can make one change in several places at once. Keep these in mind:

- Alt-click places a cursor where you click. {{Ctrl+Alt+Down}} and {{Ctrl+Alt+Up}} add cursors on the lines below and above.
- {{Ctrl+D}} adds the next match of the selected word. {{Ctrl+Shift+L}} selects every match at once.
- {{Shift+Alt}} and a drag makes a column selection across several lines.
- {{Esc}} returns to a single cursor.

```quiz
Which key adds a cursor on the next match of the selected word?
○ Ctrl+Alt+D
→ That is not a multiple-cursor shortcut in VS Code.
○ Ctrl+F
→ Ctrl+F opens the Find box. It does not add cursors.
◉ Ctrl+D
→ Each press of Ctrl+D adds the next match.
```

```quiz
What does Ctrl+Alt+Down do?
○ It deletes the current line.
→ That is Ctrl+Shift+K.
○ It moves the current line down.
→ That is Alt+Down. Ctrl+Alt+Down adds cursors.
◉ It adds a cursor on the line below the last cursor.
→ Press it again to add the line after that.
```

```quiz
How do you make a column selection?
○ Hold Alt and click where you want the cursor
→ Alt-click places a single cursor. It does not make a column selection, although it can be combined with one.
◉ Hold Shift and Alt, then drag the mouse across the lines
→ That selects the same columns on each line.
○ Hold Ctrl and click each line
→ Ctrl+click does not select a column.
```
