# 7. IntelliSense, Refactoring, Quick Fixes, and Languages

VS Code reads your code as you type. It knows which names exist, what a function expects, and where a line has a problem, and it offers help based on that. This chapter covers the help you see while typing, the tools that rename and repair code safely, and the language support that makes all of this work for Python, C#, and JavaScript.

Some of the features here need an extension for the language you are using. JavaScript works out of the box. Python and C# need their extensions, and this chapter installs them. Python also needs its own environment, which the second step creates. The last step is homework: you repair a Python file that has three deliberate mistakes, and the Problems panel and Quick Fix point you to each one.
