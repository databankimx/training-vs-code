# Checklist: checking what Copilot writes

Tick each item when you have done it.

- [ ] Read a suggestion in full before you accept it.
- [ ] Run the function, and compare the result with a value you worked out by hand.
- [ ] Test an empty input and an unusual input.
- [ ] Compare a Copilot explanation with what the code actually does.
- [ ] Find and fix the bug in `average.py`, and commit the fix.
