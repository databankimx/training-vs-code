# Checklist: the .NET command-line tools

Tick each item when you have done it in VS Code.

- [ ] Created `CommandLineDemo` with the four palette steps, and chose the `csharp` folder.
- [ ] Ran `CommandLineDemo` from the Run button's drop-down, and read the output in the terminal.
- [ ] Ran `dotnet --version` and `dotnet --list-sdks` in the terminal.
- [ ] Created `TerminalDemo` with `dotnet new console`, then built and ran it with `dotnet build` and `dotnet run`.
- [ ] Added a reference to `Calculator` with `dotnet add`, and found the `ProjectReference` line.
- [ ] Ran `dotnet test Calculator.Tests`, and found the test that fails on purpose.
- [ ] Published a single-file executable, and ran it from the publish folder.
- [ ] Matched each palette step to its terminal command in the table.
- [ ] Named the three C# extension commands, and two or more C# Dev Kit commands.
- [ ] Completed the homework, and deleted the demo folders.
