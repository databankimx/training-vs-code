# Checklist: the Source Control panel

Tick each item when you have done it in VS Code.

- [ ] Open the Source Control view with {{Ctrl+Shift+G}}, and find the changes listed in it.
- [ ] Tell an M (modified) file from a U (untracked) file.
- [ ] Open the diff view for `README.md`, and find the added line, highlighted in green.
- [ ] Stage `README.md`, and unstage it, then stage it again.
- [ ] Discard the throwaway change to `README.md`, and add the line again.
- [ ] Write a commit message, and commit the staged change with {{Ctrl+Enter}}.
- [ ] Find the branch name in the status bar.
- [ ] Run `git log --oneline -1` in the terminal, and check that it shows your message.
- [ ] Leave the other changes unstaged and uncommitted.
