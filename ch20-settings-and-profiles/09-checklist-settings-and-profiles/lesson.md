# Checklist: settings and profiles

Tick each item when you have done it in VS Code.

- [ ] Open the Settings editor with {{Ctrl+,}}, change `Editor: Font Size`, then reset it.
- [ ] Switch the Settings editor between the User and Workspace tabs.
- [ ] Open the user settings file with `Preferences: Open User Settings (JSON)`.
- [ ] Search for `word wrap`, and copy the setting ID.
- [ ] Search for `@modified`, and find the settings you changed.
- [ ] Search for `auto save`, and find the value of `files.autoSave`.
- [ ] Open the profile menu, and find the name of the current profile.
- [ ] Open the Settings Sync option, read what it would include, and do not turn it on.
