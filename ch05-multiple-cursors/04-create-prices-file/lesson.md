# Creating prices.py

The homework in this chapter changes a file called `prices.py`. Before you can change it, you need to create it, so this step covers making a new file in VS Code.

## Create the file in the Explorer

Make sure the practice folder, `training-practice`, is open in VS Code. Press {{Ctrl+Shift+E}} to show the Explorer if it is hidden. Right-click the empty space below the folder's files, and choose New File. Type `prices.py`, and press {{Enter}}.

VS Code creates the file in the practice folder and opens it in the editor. It is empty for now.

> **Create it in the practice folder:** if you create the file in `training-vs-code`, the course folder, the homework will not find it. The Explorer shows the folder name at the top of the list. Check that it reads `training-practice` before you create the file.

## Type the prices

Type the list below into the file. You can type it by hand or paste it, but typing it once helps you notice what VS Code does as you go.

```python
prices = [
    "12.50",
    "8.00",
    "3.75",
    "20.00",
]
```

As you type, VS Code adds some characters for you. When you type `[`, it adds the closing `]`. When you type `"`, it adds the closing quote. Keep typing the text, and when you reach a closing character that VS Code has already added, type over it rather than adding a second one. If you end up with an extra bracket or quote, delete it. Press {{Enter}} after each line, and VS Code indents the next line for you.

Your file should match the list above exactly, with the four prices in quotes and the square brackets on the first and last lines.

## Save the file

Press {{Ctrl+S}} to save. A dot on the file's tab shows unsaved changes, and the dot disappears when the file is saved. Check the Explorer, where the file now appears in the practice folder.

Leave the file as it is. The next step is the homework, which changes these prices.
