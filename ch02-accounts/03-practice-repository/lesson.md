# Creating the practice repository

A repository is a project folder that Git keeps a history for, and that GitHub stores for you. The practice repository is a small project that the course uses for every hands-on Git lesson. You will change its files, commit them, and break its branches, so the course gives you your own copy to ruin.

## Start from the template

Open the practice template at https://github.com/databankimx/training-vs-code-practice. It is a repository the course keeps, and you create your own copy of it from there. Your copy does not change the template.

![Figure 2.5 - Use this template button](images/ch02-use-this-template.png)

*Figure 2.5 - Use this template button*

Select Use this template, and then Create a new repository. GitHub asks for a name. Use something that tells you what it is, such as training-vs-code-practice. Tick Include all branches, so that the conflict branch comes with your copy.

![Figure 2.6 - Create a repository from the template, with Include all branches ticked](images/ch02-create-from-template-form.png)

*Figure 2.6 - Create a repository from the template, with Include all branches ticked*

Choose Private if you want your practice work out of public view. Private is a good choice for this course.

Your new repository now lives under your account, at an address with your username in it. You will use that address when you clone the repository in Chapter 12.

> **Do not use a company repository:** the exercises change files, create branches, and sometimes leave them in a mess. Keep them in your personal practice repository, never in a repository your team uses.
