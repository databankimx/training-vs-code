# 19. Extensions

Extensions add languages, tools, and features to VS Code. You have already used several in this course: the Python extension in Chapter 7, the Electron and test runners in the setup, and the GitHub Copilot extensions in Part V. This chapter covers how to find them, read what they do, turn them off without removing them, keep them up to date, and recommend them to people who open your project.

Most of the work happens in the Extensions view. Open it with {{Ctrl+Shift+X}}, or use the Extensions icon in the activity bar.

The homework adds a recommendation for the Pylint extension to the practice repository. Pylint is a code checker. It adds warnings in the editor for standards problems, such as a function with no docstring.
