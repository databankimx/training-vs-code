# Checklist: terminal and tasks

Tick each item when you have done it in VS Code.

- [ ] Open the terminal with {{Ctrl+`}}, and check that its shell is PowerShell 7.
- [ ] Open a second terminal with {{Ctrl+Shift+`}}, and split one with {{Ctrl+Shift+5}}.
- [ ] Clear a terminal with `Terminal: Clear`, and close one by typing `exit`.
- [ ] Run `Get-ExecutionPolicy -Scope CurrentUser` and read the answer.
- [ ] Run `git --version` in a new terminal, and check that it prints a version number.
- [ ] Run a task from the Terminal menu, with Run Task.
- [ ] Run the default test task from the practice folder, and read which test failed.
