# 9. Running, Debugging, and Testing in the Editor

Chapter 8 ran your code from the terminal. This chapter runs it from the editor. You will set a breakpoint, start a debug session, and stop on a line of code. From there you will step through the code one line at a time and watch the values change. Then you will run the tests from the Testing view, and read a failure at the line where it happened.

This chapter uses the Python extension you installed in Chapter 7. The practice tests use `unittest`, which ships with Python. For your own work, DataBank IMX's standard test framework is `pytest`, and the first lesson explains the difference. The debugger and the tests here are for Python. Other languages use their own extensions, and the course checks each one before it teaches it.

The last step is homework: you write a launch configuration that runs the practice repository's tests under the debugger.
