# Chapter summary

You can open a folder, find files quickly, work with more than one folder, and arrange the window. Keep these in mind:

- File, then Open Folder, or {{Ctrl+K}} then {{Ctrl+O}}, opens a folder.
- {{Ctrl+P}} finds a file by its name. {{Ctrl+Shift+E}} shows the Explorer.
- {{Ctrl+Shift+P}} opens the command palette, where almost any action can be found by name.
- Save a .code-workspace file outside the practice folder, so it is not shared through the repository.

```quiz
Which key finds a file by its name in the open folder?
○ Ctrl+N
→ Ctrl+N creates a new untitled file.
◉ Ctrl+P
→ Quick Open starts with Ctrl+P. Type part of the name and choose the file.
○ Ctrl+F
→ Ctrl+F searches inside the file you have open, not the folder.
```

```quiz
Where should you save a .code-workspace file?
◉ Outside the practice folder, such as in C:\Development
→ That keeps the workspace file out of the repository, so it is not shared with anyone who clones it.
○ Inside the practice folder, so it is shared
→ A workspace file that is shared through the repository holds your local settings. Keep it outside.
○ In the Recent folder list
→ The Recent list is not a place to save files. It only lists folders you opened.
```

```quiz
Which key combination shows the Explorer if it is hidden?
○ Ctrl+J
→ Ctrl+J shows or hides the panel at the bottom.
◉ Ctrl+Shift+E
→ That opens the Explorer view on the left.
○ Ctrl+B
→ Ctrl+B shows or hides the side bar, which is a different job from choosing the Explorer.
```
