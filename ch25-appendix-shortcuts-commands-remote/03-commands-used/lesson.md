# Commands used in the course

Press {{Ctrl+Shift+P}}, and type a command's name to run it. Names here match the Command Palette, so you can search for them exactly as written.

## Preferences and settings

- `Preferences: Open User Settings (JSON)`: opens `settings.json`. Chapter 20.
- `Preferences: Open Keyboard Shortcuts (JSON)`: opens `keybindings.json`. Chapter 21.
- `Snippets: Configure User Snippets`: opens the snippets file for a language. Chapter 21.
- `Format Document`: formats the open file. Chapter 4.
- `Toggle Line Comment`: comments or uncomments the line. Chapter 4.

## Python

- `Python: Select Interpreter`: chooses the Python version VS Code uses. Chapter 7.
- `Python: Configure Tests`: sets up the Testing view for the tests. Chapter 9.

## Terminal and tasks

- `Terminal: Toggle Terminal`: shows or hides the terminal. Chapter 8.
- `Terminal: Clear`: clears the terminal. Chapter 8.
- `Terminal: Select Default Profile`: chooses the shell the terminal opens. Chapter 8.
- `Tasks: Run Task`: runs a task from `tasks.json`. Chapter 8.
- `Tasks: Run Test Task`: runs the test task. Chapter 8.

## Git

- `Git: Clone`: clones a repository from GitHub. Chapter 11.
- `Git: Create Branch...`: creates a branch. Chapters 11 and 23.
- `Git: Delete Branch...`: deletes a branch. Chapter 11.
- `Git: Stash`, `Git: Stash (Include Untracked)`, `Git: Apply Latest Stash`, `Git: Pop Latest Stash`: set changes aside and bring them back. Chapter 11.
- `Git: Fetch`, `Git: Pull`, `Git: Push`: move commits to and from the remote. Chapter 12.
- `Git: Publish Branch...`: copies a new branch to GitHub. Chapters 15 and 23.
- `Git: Merge...`: merges a branch into the current one. Chapter 13.
- `Git: Abort Merge`: stops a merge in progress. Chapter 13.
- `Git: Undo Last Commit`: undoes the last commit, and keeps the changes. Chapter 10.
- `Sync Changes`: the button that pulls and pushes together. Chapter 12.

## Debugging, output, and trust

- `Developer: Show Logs`: opens VS Code's logs. Chapter 22.
- `Developer: Reload Window`: restarts the window without losing work. Chapter 22.
- `Workspaces: Manage Workspace Trust`: changes whether a folder is trusted. Chapter 22.
