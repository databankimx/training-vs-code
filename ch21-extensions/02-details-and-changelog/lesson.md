# Details and changelog

The details page for an extension is the place to check what it does before you rely on it. Open the Pylint extension from the Extensions view, and read the sections on the page:

- **Overview** explains what the extension does, usually with examples.
- **Feature Contributions** lists the commands, settings, and languages the extension adds, so you know what will appear in your editor.
- **Changelog** lists what changed in each version, which helps when a new version changes how something behaves.
- **Dependencies** shows any other extensions this one needs, which VS Code installs with it.

Read the changelog after an update, because that is where a change in behaviour is most likely to be described.

> **Check the license too.** The details page links to the license. Work use of an extension depends on its license, so check it before you rely on the extension at work. Our team records each extension's license before it is recommended.
