# Chapter summary

You now have VS Code installed and open, with the color theme and display language set. Keep these in mind for the rest of the course:

- The theme picker opens with {{Ctrl+K}}, then {{Ctrl+T}}.
- The display language stays English, so the menu names match the lessons.
- Restricted Mode turns off some features until you trust the folder. Trust the practice folder.
- Leave Settings Sync off for the course, so your settings match the lessons.

```quiz
Which two keys, pressed one after the other, open the color theme picker?
○ Ctrl+T on its own
○ Ctrl+Shift+T
→ That shortcut is not used for the theme picker.
◉ Ctrl+K, then Ctrl+T
→ Ctrl+K starts a two-key shortcut. Ctrl+T is the second key.
```

```quiz
Why should Settings Sync stay off for this course?
○ It stops the trust prompt from appearing for any folder.
→ Trust is set per folder, and Settings Sync has nothing to do with it.
○ It deletes the extensions you have installed.
→ Settings Sync copies extensions. It does not delete them.
◉ A copy of other settings can make your screen differ from the lessons, and can copy paths and names to another computer.
→ That is the reason. Settings Sync copies everything, so the course's settings can be mixed with yours.
```

```quiz
Which entry does winget not add to the right-click menu?
○ The Welcome tab
→ The Welcome tab is part of VS Code itself, so it is always there.
◉ Open with Code
→ winget installs VS Code, but the Explorer entry needs the installer's option or the setup script.
○ The code command in PowerShell
→ With winget, the code command should work in a new PowerShell window.
```
