# 3. Opening Folders, Files, and Layout

VS Code works on folders, not on single files. When you open a folder, the Explorer lists its files, Quick Open finds any file by its name, and the window layout decides how much of that you see at once. This chapter covers how to open a folder, how to move around inside it, and how to arrange the window so that the things you need are on screen.

Most of the chapter is practice. You will use the course folder that the setup script opened, because the practice repository is not copied to your computer until Chapter 11. Each part ends in a checklist, and the last part of the chapter gathers the checks together.
