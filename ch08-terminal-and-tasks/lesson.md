# 8. The Integrated Terminal and Tasks

So far you have worked in the editor. Much of the work a developer does happens in a terminal: running a script, starting a test suite, or using Git. VS Code has a terminal built in, so you do not need a separate window. This chapter covers opening it, choosing which shell it uses, running the course's setup script, and saving a command as a task so you can run it again with one step.

The last step is homework: you write a task that runs the tests in the practice repository, and then run it from VS Code.
