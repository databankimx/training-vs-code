# Checklist: extensions

Tick each item when you have done it in VS Code.

- [ ] Open the Extensions view with {{Ctrl+Shift+X}}, and search for `pylint`.
- [ ] Check the publisher on the Pylint extension, and install it.
- [ ] Open its details page, and find the Feature Contributions, Changelog, and Dependencies sections.
- [ ] Disable the Pylint extension, reload the window, and enable it again.
- [ ] Find the setting `extensions.autoUpdate` in Settings.
- [ ] Add `ms-python.pylint` to `.vscode/extensions.json`, and check the Recommended section.
- [ ] Commit the change to `extensions.json`.
