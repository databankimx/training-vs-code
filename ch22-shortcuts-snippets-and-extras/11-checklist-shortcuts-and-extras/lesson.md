# Checklist: shortcuts, snippets, and extras

Tick each item when you have done it in VS Code.

- [ ] Open the Keyboard Shortcuts editor with {{Ctrl+K Ctrl+S}}, and search for `toggle terminal`.
- [ ] Search the editor for a key, such as `ctrl+k`, and read the commands it lists.
- [ ] Give `Duplicate Selection` a new key, then reset it.
- [ ] Open `keybindings.json`, and read one entry in it.
- [ ] Open the Python snippets file, and read the snippet for a function with a docstring.
- [ ] Open `README.md`, and show the Markdown preview with {{Ctrl+Shift+V}}.
- [ ] Turn sticky scroll on, and find the minimap setting.
- [ ] Open the Output panel with {{Ctrl+Shift+U}}, and switch to another channel.
