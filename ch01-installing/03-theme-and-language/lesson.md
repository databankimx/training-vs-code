# Color theme and display language

VS Code has two settings here that affect what you see, and neither changes how the code works.

## The color theme

The color theme sets the colors of the whole window. The course's screenshots use the default dark theme, so if you pick the same, your screen will match the pictures. Pick a different theme if you prefer one, and the lessons will still make sense.

To change it, press Ctrl+K and then Ctrl+T. A list of themes opens. Move through it and the window changes as you go, and press Enter to keep the one you like.

## The display language

The display language changes the words on the menus and in the window. VS Code chooses one from your Windows language, and you can change it.

Keep the display language set to English while you work through this course. The lessons name menu items and commands in English, so a menu in another language would not match the words in the lesson. You can change it back at any time.

To check or change it, press Ctrl+Shift+P, type Configure Display Language, and press Enter. Choose English and let VS Code install the language pack if it asks. It restarts the window to apply the change.

> **A note on the command palette:** you have just used it. Chapter 3 explains it fully, but for now the only thing to remember is that Ctrl+Shift+P opens it and lets you type a command by name.
