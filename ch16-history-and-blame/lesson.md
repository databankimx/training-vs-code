# 15. History and Blame

Every commit you have made in this course is still in the history of your practice repository: the Chapter 12 README commit, the side and main changes from Chapter 15, and the merge. This chapter shows how to read that history from inside VS Code, so you can answer three questions:

- What changed in this file, and when?
- Who changed this line, and in which commit?
- How do two commits differ?

Nothing in this chapter changes a file, so there is no homework. Every step is a check. The terminal commands in each lesson show the same information, and you can use them to confirm what you see in VS Code.

Use your `training-vs-code-practice` folder. Its `calculator.py` has the most history, which makes it the best file to practise on.
