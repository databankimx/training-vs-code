# Windows shortcuts

A chord is two presses, one after the other, shown as `Ctrl+K, then Ctrl+S`. Chords are listed with the first key, then the second. Keys written as `Ctrl+Shift+P` are pressed together.

Shortcuts marked "verify" are used in the course but are not on Microsoft's official Windows keyboard shortcut sheet, so check them in your build before you rely on them. Mac keys are a guide; see the Mac lesson for the rule and the exceptions.

## Keys used with the mouse

Alt (hold and click) and Shift+Alt (hold and drag) are listed above with the cursor and selection shortcuts, because they change what a click or drag does rather than running a command on their own.

## The complete list

The tables above cover every shortcut the lessons use. For the full set of Windows shortcuts in VS Code, including the ones the course does not use, see the [official Windows keyboard shortcuts sheet](../docs/keyboard-shortcuts-windows.pdf). It is a copy of Microsoft's PDF, stored with this course, and it is the place to check any of the "verify" entries above.
