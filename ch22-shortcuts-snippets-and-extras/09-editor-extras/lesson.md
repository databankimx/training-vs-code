# Editor extras

Some editor features do not change your code. They help you read it. This lesson covers four of them, and each one is a setting you can turn on or off.

## Bracket pair colorization

Matching brackets get the same colour, so you can see which opening bracket goes with which closing one. Nested code with many brackets becomes much easier to follow. The setting is `editor.bracketPairColorization.enabled`, and it is usually on already.

## Sticky scroll

In a long function, the header can scroll out of view, and you lose track of where you are. Sticky scroll keeps the enclosing lines at the top of the editor as you scroll. Search the Settings editor for `sticky scroll` and turn it on. The setting is `editor.stickyScroll.enabled`.

## The minimap

The minimap is a small picture of the whole file, on the right side of the editor. Click it to jump to another part of the file. It is useful for finding a block of code by its shape. Turn it on or off with the setting `editor.minimap.enabled`.

## The Outline view

The Outline view lists the functions, classes, and sections in the current file, in the Explorer. Click an item to jump to it. It is the quickest way to move around a file with many functions in it.

> **Try each one, then decide.** Turn each setting on, use it on a long file for a few minutes, and keep only the ones you find useful.
