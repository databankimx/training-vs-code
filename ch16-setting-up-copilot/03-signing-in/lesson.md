# Signing in

Copilot does not make suggestions until you sign in. In the build of VS Code you use for this course, Copilot is already included, so there is nothing to install or enable first. Signing in is the whole setup.

![Figure 16.1 - The Copilot robot icon in the status bar](images/ch16-status-bar-icon.png)

*Figure 16.1 - The robot icon in the status bar*

## The steps

1. Click the robot icon in the status bar, at the bottom of the window.
2. Select **Sign in** from the menu.
3. Your browser opens GitHub's sign-in page. Sign in with your personal account, and follow the prompts.
4. Return to VS Code. The robot icon's menu now shows your plan, which the next lesson covers.

![Figure 16.2 - The Sign in dialog](images/ch16-sign-in-dialog.png "width=50%")

*Figure 16.2 - The sign-in dialog that opens from the robot icon*

## Check the address

Before you enter your details, check that the browser address starts with `https://github.com`. If a page asks for your GitHub password somewhere else, close it. A genuine sign-in from VS Code does not send you to another site for your password.
