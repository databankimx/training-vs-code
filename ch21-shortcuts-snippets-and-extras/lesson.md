# 21. Keyboard Shortcuts, Snippets, and Other Extras

Once you know the basics, the fastest way to get faster is to make VS Code fit your hands. This chapter covers the Keyboard Shortcuts editor, the file where your shortcuts live, chord shortcuts that take two presses, snippets that type repeated code for you, and a handful of editor features that make long files easier to read.

You will change one shortcut, write one snippet, and look at the Markdown preview. Each homework step changes a file, so each one has a starter and a worked solution.
