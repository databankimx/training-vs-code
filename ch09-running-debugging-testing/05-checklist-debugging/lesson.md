# Checklist: running, debugging, and testing

Tick each item when you have done it in VS Code.

- [ ] Run `Python: Configure Tests`, choose unittest, and see the three tests in the Testing view.
- [ ] Run all three tests with the play icon, and click the failing test to read its message.
- [ ] Set a breakpoint in `calculator.py` with {{F9}}, and see the red dot in the gutter.
- [ ] Debug one test from the Testing view, and stop at your breakpoint.
- [ ] Step over a line with {{F10}}, and see a value change in the Variables panel.
- [ ] Add an expression to the Watch panel, and read its value.
- [ ] Open the Debug Console with {{Ctrl+Shift+Y}}, and evaluate an expression while paused.
- [ ] Continue with {{F5}} until the session ends, and find the failing test in the Testing view.
- [ ] Open the Run and Debug view with {{Ctrl+Shift+D}}, and find the `launch.json` link.
