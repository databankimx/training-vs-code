# 4. Typing, Selecting, and Moving Text

Most of your time in an editor goes on changing text that is already there. This chapter covers the keys for undoing and redoing, moving and copying lines, commenting out code, and tidying up the layout of a file. Knowing these keys means you spend less time selecting text with the mouse, and more time on the code itself.

The practice file for this chapter is `calculator.py` in your practice folder. The last step is homework, which fixes some formatting problems in that file. You make every change in VS Code, not in the runner, and a worked solution sits behind a spoiler in the runner, for when you are stuck.
