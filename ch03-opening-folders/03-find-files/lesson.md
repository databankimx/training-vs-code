# Finding files

There are two quick ways to find a file in the folder you have open. The Explorer shows the whole folder as a tree, and Quick Open finds one file by its name.

## Quick Open

Press Ctrl+P and start typing part of the file name. VS Code lists the matching files as you type. Use the arrow keys to pick one, and press Enter to open it.

![Figure 3.2 - Quick Open results for a file name](images/ch03-quick-open.png)

*Figure 3.2 - Quick Open results for a file name*

Quick Open does not need the Explorer to be open, and it does not need you to know which folder the file is in. It is the fastest way to reach a file you know the name of.

## The Explorer

The Explorer is the top icon in the activity bar on the left. It shows the open folder as a tree. Select a folder's arrow to open it, and select a file to open it in the editor.

![Figure 3.3 - The Explorer with a folder expanded](images/ch03-explorer-expanded.png)

*Figure 3.3 - The Explorer with a folder expanded*

If the Explorer is not showing, press Ctrl+Shift+E to bring it up. Right-clicking an item in the Explorer gives you the usual file actions, such as New File and Rename. You do not need those yet, so leave the practice folder as it is.
