# 21. Settings and Profiles

VS Code does almost everything through settings. The font size, the rulers, whether a file is formatted when you save it, and which terminal opens are all settings. This chapter shows where those settings live, how to find one when you know only what you want, how to keep a separate set of tools for different kinds of work, and why you should think before you sync your settings anywhere.

By the end of this chapter, you will change a setting in the file that holds your settings, and confirm the change on screen.
