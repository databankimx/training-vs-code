# Checklist: merge conflicts

Tick each item when you have done it in VS Code.

- [ ] Create the conflict in `calculator.py` with the first lesson's steps, and leave it in place.
- [ ] Find the conflict markers in `calculator.py`, and tell the current change from the incoming change.
- [ ] Use one of the Accept links above a conflict, and check that its markers are gone.
- [ ] Open a conflicted file in the Merge Editor, from the Merge Changes group.
- [ ] Identify the Current, Incoming, and Result panes in the Merge Editor.
- [ ] Complete the merge with a commit, and check it with `git log --oneline --graph -5`.
- [ ] Run `git status`, and check that the working tree is clean.
- [ ] Click Sync Changes, and check that `git status -sb` shows no ahead count.
