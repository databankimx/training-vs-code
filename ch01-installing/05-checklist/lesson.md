# Checklist: first launch

Work through this list. Each item is something you can see in the window or in a menu. If an item does not match, go back to the step it names before you move on.

- [ ] VS Code opens, and you have noted its version from Help, then About.
- [ ] You have answered the workspace trust prompt for one folder.
- [ ] The color theme is the one you chose.
- [ ] The display language is English, or it is the language you chose on purpose.
- [ ] Settings Sync is off.
- [ ] You know where the account icon is, and you have signed in, or you have decided to sign in later.

Chapter 2 creates your GitHub account and the practice repository. You will need the account before you reach the GitHub chapters.
