# 18. Suggestions and Chat

Copilot works in two ways. Suggestions appear as you type, in grey text that you can accept or dismiss. The chat panel answers questions about code you choose. This chapter shows both, on the sample code in the course.

> **Copilot use rule.** The free tier of GitHub Copilot is permitted for learning, and this course uses it for that purpose. Use it only with the sample code in this course, and never for DataBank work. DataBank work happens only through company-provided accounts, under the AI Acceptable Use Policy.
