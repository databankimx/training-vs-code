# Settings used in the course

Search the Settings editor with {{Ctrl+,}} for any name below. A setting marked "user" is usually changed in user settings. Settings that a project needs can go in workspace settings, which Chapter 20 covered.

## Editor

- `editor.fontSize`: the size of the text in the editor. Chapter 20.
- `editor.rulers`: the vertical lines that mark columns. Chapter 20.
- `editor.wordWrap`: wraps long lines to fit the window. Chapter 4 (Alt+Z).
- `editor.formatOnSave`: runs the formatter when a file is saved. Chapter 20.
- `editor.stickyScroll.enabled`: keeps enclosing lines at the top of the editor. Chapter 21.
- `editor.minimap.enabled`: shows the minimap on the right side. Chapter 21.
- `editor.bracketPairColorization.enabled`: colours matching brackets. Chapter 21.

## Files

- `files.autoSave`: when files are saved automatically, such as `afterDelay`. Chapter 20.
- `files.autoSaveDelay`: the pause, in milliseconds, before `afterDelay` saves. Chapter 20.

## Git

- `git.rebaseWhenSync`: makes a sync rebase instead of merging, so history stays in a line. Chapter 12.

## Extensions

- `extensions.autoUpdate`: whether extensions update themselves. Chapter 19.

## Copilot

- `github.copilot.enable`: turns Copilot suggestions on or off for each language. Chapter 16.

## Python

- `python.defaultInterpreterPath`: the Python program VS Code uses for a project. Chapter 20 used it as an example of a setting that should not sync.
