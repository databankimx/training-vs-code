# Checklist: when things go wrong

Tick each item when you have done it in VS Code.

- [ ] Open the Output panel with {{Ctrl+Shift+U}}, and read the newest lines in the Git channel.
- [ ] Open the logs with `Developer: Show Logs...`, and find the extension host log.
- [ ] Reload the window with `Developer: Reload Window`, after saving your files.
- [ ] Run `code --disable-extensions .` from your practice folder, and check that the window opens with no extensions.
- [ ] Reset a changed setting from the Settings editor, using the gear icon.
- [ ] Search the Keyboard Shortcuts editor for a key, and find the command that owns it.
- [ ] Check the Workspace Trust status for your practice folder, with `Workspaces: Manage Workspace Trust`.
