# Updates

VS Code updates your extensions automatically by default. When an update is waiting, a number appears on the Extensions icon in the activity bar, and the Extensions view lists the updates under Updates.

You can update one extension by hand. Open its details page, or right-click it in the Extensions view, and choose Update. Some updates need a reload, and VS Code asks you if they do.

Automatic updates are controlled by a setting, `extensions.autoUpdate`. It is on by default. If you want to review each update before it arrives, change that setting to off, and update by hand.

> **Read the changelog after an update.** An update can change a default or a warning. The changelog on the details page is the quickest way to see what changed.
