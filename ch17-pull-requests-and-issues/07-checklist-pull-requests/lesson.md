# Checklist: pull requests and issues

Tick each item when you have done it. You can use the website, VS Code, or both.

- [ ] Create `pr-practice`, commit a README change on it, and publish it with `Git: Publish Branch...`.
- [ ] Open a pull request from `pr-practice` into `main`, on the website or from the GitHub Pull Requests view.
- [ ] Write a title and a description that say what changed and what to check.
- [ ] Find the Checks section, and note that the practice repository has no checks.
- [ ] Leave a comment on a line in Files changed, and submit it as a Comment review.
- [ ] Reply to your comment in the Conversation tab.
- [ ] Merge the pull request, and delete `pr-practice` on GitHub.
- [ ] Sync `main` on your computer, and delete the local `pr-practice` branch.
- [ ] Open an issue, and link it from the pull request with `Closes #` and the issue number.
