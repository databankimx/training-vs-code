# 2. Creating Your Accounts

The later chapters use GitHub for practice. You will push changes to it, open pull requests on it, and sign in to it from VS Code, which Chapter 12 covers. This chapter sets up the account you need for that, and it creates the practice repository you will break on purpose later.

If you already have a GitHub account, you can skim the first two steps and make sure the settings match. If you have never used GitHub, go through them in order. Nothing here costs money.

> **Personal accounts only:** the course uses a personal GitHub account for all of its practice. Company accounts cannot create repositories directly on GitHub Enterprise, so the practice repository has to live in a personal account. Use yours for every step in this chapter and the rest of the course.
